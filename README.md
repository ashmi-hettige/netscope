# NetScope — Multithreaded Network Service & Port Scanner
EC5205 Operating Systems & Network Programming · University of Ruhuna · 25th Batch

**Status: work in progress.**

A Java client–server tool that scans a range of TCP ports on an authorised host,
streams live progress over UDP, and returns a reliable report over TCP, using a
thread pool to scan ports in parallel.

> **Ethical use:** scan only hosts you own or are authorised to test
> (for example `127.0.0.1`, your own machine).
